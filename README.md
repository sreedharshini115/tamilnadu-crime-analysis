# Tamil Nadu Crime Data Analysis

## Project Overview
This project focuses on analyzing crime data from Tamil Nadu using Python. It explores crime patterns, crime counts, and crime rates to understand the dataset.

## Objectives
- Clean and prepare the crime dataset.
- Perform Exploratory Data Analysis (EDA).
- Explore crime patterns across cities and years.
- Prepare features for machine learning.

## Dataset Description
The dataset contains the following columns:
- City
- Latitude
- Longitude
- Year
- Crime_Type
- Crime_Count
- Population
- Crime_Rate_per_100k
- Record_ID
